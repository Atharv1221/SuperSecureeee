About Private Space

Private Space is a single-file, one-way message archive. It runs entirely in your browser — there is no server, database or account system involved.

Permanent messages live in this file's source code. Local messages you add through the + button are saved only in this browser's storage.

Security note: the PIN screen only hides content inside this page — it is a UI gate, not encryption or a server-side login. Anyone with access to the page's source can read the PIN check and the embedded messages. Do not rely on it for anything truly sensitive unless the message data itself is encrypted first.
